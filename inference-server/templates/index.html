Inference Server Curation

Data browser for the YOLO/ALPR inference server's own traffic - every image submitted to /predict or /alpr/predict (or frame over /alpr/ws) is logged here alongside its detections, so the models' real-world behavior can be inspected and curated after the fact.

Features

  • Thumbnails - a small preview rendered at capture time, shown inline in the Submitted Images list.
  • Capture metadata - EXIF pulled from the image (camera make/model/focal length/GPS, when present) plus which host ran inference, kept separate from detection metadata.
  • Detection metadata - a denormalized YOLO detection summary (count + per-class counts) alongside the full per-box Detection Labels.
  • LLM-generated descriptions - an accessibility-alt-text-style caption + keywords, generated in the background by a colocated multimodal LLM, editable by hand.
  • User tags - free-form, case-sensitive labels applied to any submitted image.
  • Full-text search + lexical sorting - every column below, including JSON blobs and long file paths, is searchable (substring by default; quote for case-sensitive whole-word; * for regex) and sortable.
